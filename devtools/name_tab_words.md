## รายการสำหรับ copy ลงชีต

```
เลเวล
เอฟเฟค
เควน
เดรก
เอลฟ์
อาร์คมิวตา
อาร์คมิวทา
คาร์ไล
คาร์ไลล์
เพนไนท์
ฟอร์มาดิไฮล์
แฮร์ริ่ง
เรจินัล
```

หมายเหตุ:
- `เอฟเฟกต์` (สะกดมาตรฐาน) อยู่ในพจนานุกรมแล้ว — ถ้าแก้ที่คำแปลเป็นสะกดมาตรฐานก็ได้
  ไม่ต้องเพิ่ม `เอฟเฟค` ลงชีต
- `อาร์คมิวตา`/`อาร์คมิวทา` สะกดต่างกันสองแบบในคำแปล ควรรวมให้เหลือแบบเดียว
  (`คาร์ไล`/`คาร์ไลล์` ก็เช่นกัน)
- `เดรก` ในเกมปรากฏเป็นส่วนของ `แมนเดรก` (mandrake) และ `เอ็นเดรกา` (Endrega) เท่านั้น
  การเพิ่มคำนี้ทำให้ทั้งสองชื่อไม่ถูกฉีกที่รอย `เด|รก`

## คำสะกดผิดในคำแปล — ชุดแก้ไขพร้อมใช้ (typos.csv)

รายการแก้ไขครบทุกแถวอยู่ที่ **`devtools/typos.csv`** (2,032 แถว: ประเภท · แหล่ง · id · ปัจจุบัน · ที่ควรเป็น)
เปิดด้วย Excel/Google Sheets ได้ทันที — **สร้างใหม่ได้ตลอด** ด้วย:

```bash
.venv/bin/python devtools/find_typos.py     # อ่านคลังแปล → เขียน typos.csv + สรุป
```

สคริปต์ผลตรงกับชุดที่ตรวจทานโดยคนครบทุกแถวทั้งลำดับ (ตรรกะกรองอ่านได้ในไฟล์ — เช่น ทำไม าา
ลากเสียงไม่ถูกจับ) เมื่อทีมแปลแก้คืบหน้าเท่าไหร่ รันซ้ำแล้วจำนวนแถวจะลดลงตาม

ยอดรวม 2,032 แถว จาก 2,026 ข้อความไม่ซ้ำ (1.15% ของคลัง 176,230 — บางข้อความมีมากกว่าหนึ่งปัญหา)

| ประเภท | แถว | หมายเหตุ |
|---|--:|---|
| เ+เ → แ | 1,549 | **แก้ bulk ปลอดภัย** — ทุกแถวเป็นการ replace ตรง และคลังแปลไม่มี `เเ` เหลืออยู่นอกรายการนี้เลย |
| สระ/วรรณยุกต์ซ้อน | 412 | ไม้เอก 126 · สระอู 84 · ไม้โท 61 · สระอุ 49 · ไม้หันอากาศ 45 · สระอี 31 · อื่นๆ 16 (นับชนิดแรกที่ซ้อนในแต่ละแถว) |
| จักพรรดิ (สะกดผิด 4 แบบ) | 37 | ดูตารางด้านล่าง |
| มงกุฏ → มงกุฎ | 24 | |
| คนเคราะ/คนเคระ → คนแคระ | 6 | ยืนยันจาก key อังกฤษ "Dwarven spirit" = เหล้าคนแคระ |
| บรรได → บันได | 4 | |

ผลต่อการตัดคำเมื่อแก้ตามชุดนี้ (วัดจริงด้วย wrapper + คำแท็บชื่อ 13 คำ): จุดตัดเพิ่มขึ้น 226 ข้อความ
(คำกลับมาถูกตัดตามคำจริง เช่น `มาเเล้ว → มา|แล้ว`) · จุดตัดลดลง 452 ข้อความ (คำสะกดผิดที่เคยถูกฉีก
เป็นตัวอักษรโหดๆ กลับมาเป็นคำเดียวถูกต้อง เช่น `สู|ู|ตร → สูตร`) — ดีขึ้นทั้งสองทิศทาง

### เตือนภัยเบลอตา: เเ (สระเอสองตัว) แทน แ

`เเล้ว` กับ `แล้ว` เรนเดอร์ด้วยตาเกือบจะเหมือนกันเป๊ะแต่คนละ codepoint — `เเ` คืออักขระ
U+0E40 (เ) สองตัว ส่วน `แ` เป็นอักขระเดี่ยว U+0E41 — พบใน 1,132 ข้อความ unique ครอบคลุมหมด
ใน CSV แล้ว ภาษาไทยไม่มีกรณีที่สะกด `เเ` ถูกต้อง (คำไทยไม่ลงท้ายด้วยสระเอเปล่า เพราะเป็นสระ
หน้าที่ต้องมีพยัญชนะตามหลังเสมอ) จึง replace ทั้งชุดได้โดยไม่ต้องดูทีละแถว

### าา ไม่ใช่คำผิด — อย่าแก้

การลากเสียงในบทพูด (อาา, อาาาาาา) เป็นเจตนาของผู้แปล ไม่ได้อยู่ในรายการ —
กฎ "สระ/วรรณยุกต์ซ้อน" ของ `find_typos.py` จับเฉพาะสระจ่อย/วรรณยุกต์/ไม้ที่ซ้ำกันเอง
เพราะพยัญชนะหนึ่งตัวใส่เครื่องหมายชนิดเดียวกันซ้ำไม่ได้ในภาษาไทย ส่วนตัว**ฐาน**ซ้ำ
(าา ใน อาา, กกก ใน ฮั่กกก) ไม่เข้าข่ายกฎนี้อยู่แล้ว จึงไม่ต้องมี blacklist พิเศษ

### หืืม / อืืมม / ถุงมืือ (4 จุด) — ผิดแน่นอน แก้ได้ทั้งหมด

สระ ื ซ้อนทั้ง 4 แถวเป็นคำสะกดผิด (ยืนยันโดยทีมแปล): หืืม → หืม, อืืมม → อืมม, ถุงมืือ → ถุงมือ
(key อังกฤษ: Tracker's gauntlets) — การลากเสียงในภาษาไทยทำที่ตัวพยัญชนะ/สระหลังแบบตัวฐาน
(หืมมม, อาา) ไม่มีกรณีซ้อนสระจ่อยอย่าง ื ถูกต้อง จึงไม่มีข้อยกเว้นสำหรับกลุ่มนี้

### จักรพรรดิ — สะกดผิด 5 แบบในคำแปล (ยืนยันด้วยการนับในคลังแปล)

คำที่สะกดถูก**ตัดคำเหมือนกันเป๊ะทั้งพจนานุกรมเก่าและใหม่** ไม่มีปัญหาการตัดคำ:
`องค์|จักรพรรดิ|จะ|นำ|สันติ`

"พรรดิ" ที่เคยปรากฏในรายการวิเคราะห์รอบแรกเป็นผลพลอยได้จากวิธีเปรียบเทียบ — เป็นชิ้นที่พจนานุกรม
เก่าตัดออกมาจากคำที่สะกดผิด ไม่ใช่ run ที่ยืนเดี่ยว ของจริงคือคำแปลสะกดผิดกัน 5 แบบ
(พจนานุกรมใหม่ฉีกคำที่สะกดผิดถี่กว่า จึงเห็นชัดขึ้น):

| รูปสะกด | พบ | สถานะ |
|---|--:|---|
| จักรพรรดิ | 448 | ✓ ถูก |
| จักพรรดิ | 30 | ขาด ร |
| จักดิพรรดิ | 4 | เกิน ดิ |
| จักรดิพรรดิ | 2 | เกิน ดิ |
| จักร์พรรดิ | 1 | เกิน ์ |
| **รวม** | **485** | **ผิด 37** |

ตัวอย่างที่ผิดสะกดแล้วถูกฉีกเพี้ยน:

```
"จักพรรดิไม่ละสายตา"
  เก่า: จัก|พรรดิ|ไม่|ละ|สายตา
  ใหม่: จัก|พรร|ดิ|ไม่|ละ|สายตา
```

→ แก้ที่คำแปล: ค้นหา/แทนที่สี่รูปผิดเป็น `จักรพรรดิ` (30 + 4 + 2 + 1 = 37 จุด)

## ไม่ต้องทำอะไร

เสียงลากยาว/คำซ้ำ เช่น `ช่ายย` `ฮั่กกก` `ฮืมมม` `เบอรรร` `สสสส` — ฉีกแล้วไม่เสียหาย
เพราะไม่ใช่คำที่มีความหมายต่อเนื่อง และจุดตัดบรรทัดตรงนั้นไม่ทำให้อ่านผิด

## ภาคผนวกทางเทคนิค (สำหรับอนาคต)

พบ tie-break หนึ่งจุดในอัลกอริทึม DP ของ `core/thai_wrap.py`: เมื่อสองเส้นทางมีต้นทุน
(unknown, count) เท่ากันเป๊ะ เส้นทางที่ถูกค้นพบจากตำแหน่ง i ที่น้อยกว่าชนะ (เพราะเทียบด้วย
`<` เท่านั้น) ตัวอย่างที่สังเคราะห์ได้: `เดรกบิน…` อาจแพ้ `เด|รกบิน` (ทั้งคู่เป็นคำในพจนานุกรม)
— ไม่เกิดขึ้นในข้อมูลเกมปัจจุบัน แต่ถ้าวันหน้าเจอชื่อใหม่ที่ถูกฉีกทั้งที่เพิ่มคำแล้ว ให้ดูจุดนี้
(ทางแก้ที่เป็นไปได้: เทียบ `<=` เพื่อให้เส้นทางจากคำยาวกว่าชนะเมื่อเสมอ แต่ต้องเช็คผลกระทบ
ต่อการตัดคำทั้งชุดก่อน)
