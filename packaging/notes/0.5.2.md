### ใหม่
- ไฟล์สำหรับ macOS (ทดลอง) แนบมาใน Release เดียวกับ Windows แล้ว (`ThaiW3Setup-x.y.z-macos-arm64.zip`)

### แก้ไข
- macOS: ปุ่มแจ้งอัปเดตไม่ส่งไฟล์ของ Windows ให้อีก และแจ้งเฉพาะเวอร์ชันที่มีไฟล์ของ Mac จริง
- macOS: บางแท็บวาดไม่ครบตอนเปิดครั้งแรก (เช่นคอลัมน์ซ้ายของแท็บชื่อเฉพาะ)
- macOS: หัวข้อ ไอคอน และโลโก้เล็กกว่าที่ควร
- macOS: ปุ่มที่ปิดใช้งานอยู่ดูเหมือนกดได้
- macOS: สลับโหมด Light/Dark ขณะเปิดโปรแกรมแล้วสีค้างเป็นชุดเดิม
